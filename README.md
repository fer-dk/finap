EL siguiente desarrollo en Flask fue diseñado priorizando buenas prácticas de ingeniería, separación de responsabilidades y patrones de diseño.
La aplicación implementa una estructura basada en capas: Blueprints, Aplication/Services, Domain y Repositories/ORM Models. El objetivo es contruir una aplicación backend desacoplada, mantenible y cercana a un entorno real de producción.
Buscando profundizar conceptos de POO, diseño de software, arquitectura y despliegue.
